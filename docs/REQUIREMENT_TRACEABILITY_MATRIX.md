## 1. Aturan pembacaan

Satu baris per ID kebutuhan final. Route adalah nama beserta method/URI dari `route:list --json`, bukan tebakan endpoint berdasarkan nama controller. Callback Google tanpa nama dicatat khusus pada baris AUTH-001. Kolom code dapat memuat layanan pendukung di luar controller route. Model/table adalah entity utama, bukan seluruh tabel transitif.

`IMPLEMENTED` berarti perilaku tersedia pada HEAD, bukan semua test lulus atau bebas defect. `IMPLEMENTED_WITH_EXTERNAL_DEPENDENCY` berarti implementasi tersedia tetapi membutuhkan provider/runtime eksternal yang belum diverifikasi end-to-end. `NEEDS_VERIFICATION` berarti belum ditemukan test khusus/benchmark atau bukti yang cukup untuk mengesahkan kebutuhan tersebut. `OUT_OF_SCOPE` pada daftar batas tidak dijadikan kebutuhan implementasi baru.

Test yang dicantumkan adalah file terkait dan dapat hanya mencakup sebagian kontrak. Tidak ditemukan test khusus ditulis eksplisit; acceptance SRS bukan bukti eksekusi. Run A: 740/745 lulus, 2269 assertion, 2 failure +3 error. Run B override database queue: 744/745 lulus, 2303 assertion, 1 failure. Tidak ada klaim 745 lulus hasil menggabungkan kedua run.
